What's new in NOVARA

VERSION 3.1 • SEPTEMBER 2026
Continue Watching fixed

Random and placeholder titles are removed. NOVARA now saves only real playback progress from a title you actually started.

Dedicated Settings

Settings now has Appearance, Playback, Continue Watching, Beta, and About tabs.

New Beta section

Experimental features can be enabled individually and saved on this device, including experimental playback and interface features.

Cleaner TV progress

Changing episodes no longer creates fake zero-progress cards.

TV Remote controls

TV Remote mode is now optional in Settings. When enabled, you can navigate titles with the arrow keys, press OK to select and play, use Back to return home from playback, choose streaming providers, and use the on-screen keyboard for search.

Instant remote playback

Highlight a movie or show and press OK to start it directly. While watching, Back exits playback and returns to the NOVARA home screen.
